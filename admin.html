Your calendar link for Airbnb and VRBO

Paste this link into each platform once:

https://newriverlogcabinretreat.com/calendar.ics

  1. Airbnb: Calendar → Availability → Connect to another website → Import calendar → paste the link, name it "Direct bookings".
  2. VRBO: Calendar → Import & export → Import a calendar → paste the link.

Airbnb and VRBO re-check this link on their own schedule, usually every few hours, so a brand-new direct booking can take a little while to show there.
